# L'amour Home — Company Profile Website

موقع تعريفي ثابت (Static Website) وليس متجرًا إلكترونيًا.

## الملفات
- `index.html` — كل محتوى الصفحات والأقسام.
- `style.css` — التصميم والألوان والخطوط والاستجابة للموبايل.
- `logo.png` — اللوجو الذي تم رفعه في المحادثة.

## التعديل
افتح `index.html` في VS Code أو أي محرر نصوص، وعدّل:
- اسم الشركة والنصوص.
- رقم الهاتف والبريد الإلكتروني.
- العناوين والمحتوى داخل الأقسام.

الألوان الأساسية موجودة في أول `style.css` داخل `:root`:
`--navy` و `--pink` ويمكن تغييرها بسهولة.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفعه على أي استضافة Static مثل Netlify / GitHub Pages / Cloudflare Pages.
